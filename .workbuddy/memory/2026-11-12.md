## 修复 `source.grammar.inflection_dimensions` 崩溃

- 报错 `undefined is not an object (evaluating 'source.grammar.inflection_dimensions')` 来自 `src/core/engines/fontInput.ts:117`。
- 根因：`src/utils/conlangFont.ts:149` 用 `invoke<GrammarLoadResult>("load_grammar")`，但 Rust `load_grammar` 返回的是裸 `GrammarConfig`（`grammar.rs:42` 的 `.map(|res| res.config)`），于是 `parentGrammar.config === undefined`。
- 触发面：只有 `phonology.font_input.use_parent_phonemes === true` 且不规则词形能继承父词时才走该分支。TERRAX 拆分后的 `lamitic语系工作区` 里只有**西湾语 l_west**（5724 条 override 全部挂父词）。
- 修法：改用 `load_grammar_with_revision`；并给 index 构建加 try/catch，失败时回落 `EMPTY_FONT_INPUT_INDEX` 而不是整页崩。
- 教训：`load_*` 系列返回类型不统一——`load_grammar`/`load_all_words` 是裸对象，`load_phonology`/`load_grammar_with_revision` 是 `{config, revision}` 包装，invoke 泛型要逐个核对 Rust 签名。

## 修复西湾语 ʃ/ʒ 漏进字体（`source_substitutions` 未生效）

- 现象：`ēghis`、`kozina` 的原生文字里混进 IPA 的 ʃ / ʒ（系统字体回退），并且 `i` 退化成独立载体 `lam.carrier.i`。
- 根因：`phonemesToFontInput` 先在 `Object.keys(config.phonemes)` 里找音素，**匹配成功后**才查 `source_substitutions`。西湾音系没有 ʃ/ʒ，于是走「未知字符原样输出」分支，`{ʃ:s, ʒ:z}` 从未应用。
- 修法：`source === true` 时把 `source_substitutions` 的键并入匹配集，再用 `substitutions[phoneme]` 查表。
- 验证：西湾 420 条词条中 419 条与字体包 `lexicon_spelling.json` 的 `font_input_roman` 完全一致；唯一差异 `nēk·hīdhan` 仅缺词素边界 `·`，hb-shape 结果相同。
- 关键背景：西湾 `font_input.use_parent_phonemes = true`（七支里仅此一支），字体输入按**父语音位**生成，所以 `ēghis` 的正字是 `ēkis`（保守拼写 + s/z 合并），不是 `ēghis`。
