# 词典

核心模块，以侧边栏 + 编辑面板的分栏布局管理所有词条。

**导航**：点击左侧 `词典`

## 词条管理

左侧面板显示所有词条列表，点击后右侧打开编辑器。

| 操作 | 说明 |
|------|------|
| 新增词条 | 点击侧边栏 `+` 按钮创建空白词条 |
| 编辑词条 | 右侧面板实时编辑，自动 debounce 保存（500ms） |
| 删除词条 | 编辑面板顶部删除按钮，需确认 |
| 搜索 | 按罗马音、释义、定义、用法说明、标签或已绑定概念名称过滤 |
| IPA 模糊搜索 | 开启 IPA 搜索模式，输入 IPA 按语音相似度排序结果 |
| 高级与快捷筛选 | 支持按词性、全部 7 种词源类型、标签、生命周期状态，以及 5 项内置快捷筛选（未绑定概念 / 缺少例句 / 待定释义 / 借词待核对 / 已废弃）组合筛选 |
| 表格编辑弹窗 | 点击侧边栏「词典」标题右侧的表格图标，打开 `Word × Sense` 高密度虚拟化表格视图，支持列显隐、`Enter / ↑ / ↓` 连续录入、行首一键定位详情，以及 TSV/CSV 剪贴板粘贴预览导入 |
| 按义项批量编辑 | 多选词条后可选择作用范围（全部义项 / 仅空缺字段 / 仅首义项），筛选隐藏了部分已选词条时会醒目提示数量，并在提交前展示前后差异预览 |

## 义项与概念绑定

每个词条支持多个义项，每个义项可独立配置：

- **词性 (POS)** — 从语法模块定义的词性列表中选择
- **简明释义 (Gloss)** — 用于行间标注的简短翻译
- **核心概念绑定 (`concept_id`)** — 从内置 158 项 CLDF / Concepticon 核心概念库（涵盖 Swadesh-100 与 Leipzig-Jakarta-100）或项目自定义概念中选择绑定，支撑全语系同源词矩阵对齐
- **义项级变位类覆盖** — 为一词多义中不同用法单独指定变位类（优先于词条级变位类）
- **用法说明 (`usage_note`)** — 语域、搭配或语用备注
- **详细定义与例句** — 多行完整释义与用法示例

## 结构化词源与可点击溯源链

词源区块明确区分 7 种词源关系（`先验造词`、`后验参考`、`继承演化`、`借词`、`内部派生`、`多词素复合`、`混合`）：

- **DAG 多词素构词成分**：派生词与复合词可从当前词典选择多个词根、前缀、后缀成分并排列顺序；当底层成分读音更新后，质检会自动提醒复合词读音过期。
- **语义变化分类**：独立记录语音演变与语义演变类型（保持不变、词义缩小、词义扩大、语义转移、隐喻引申、新增义项、替代旧义）。
- **借入来源快照**：借词（含跨项目借词）完整保存借入时的供语词形、释义与语言/语系名称；即使供语后续改词或删词，历史依据依然保留。
- **可点击词源追溯链与词族树**：展开词源链可逐级查看来源词条（本语言直接定位，父语/供语自动切换语言并选中目标词）；断链会高亮提示并支持一键清理失效引用。详情页同时内嵌 **同源与派生词族面板**、**屈折范式预览**与**语料反向索引（Concordance）**，点击例句即可直达对应语料行。

## IPA 自动生成

- 编辑罗马音时，自动通过罗马音映射表 → 音位变体规则生成 IPA
- 可锁定为手动模式（🔒），自由编写 IPA
- 解锁后（🔓）恢复自动生成

:::tip
只要词条的 IPA 处于自动模式（🔓），修改罗马音映射或音位变体规则后，再次打开词条时 IPA 会自动重新计算。
:::

## 快速录入

点击右上角 ⚡ 按钮打开快速录入弹窗：

1. 输入 **单词**（罗马音）
2. 输入 **释义**
3. 选择 **词性**
4. 按 **Enter** 保存 → 自动清空，继续录入下一个
5. 按 **Esc** 关闭

:::tip
快速录入非常适合突然想到新词的时候，无需离开当前页面。弹窗会显示已保存的词条数量。
:::

## 演化路径

对于来源为 `演化 (Evolved)` 或 `借词 (Borrowed)` 且存在父词引用的词条，编辑器会显示演化路径。

- 支持跨多代语言显示全路径（例如：`a → ab → abc`）
- 相邻重复词形会自动去重（例如：`a → a` 显示为 `a`）
- 下方保留已应用音变规则标签（若存在）

## 质量检查

**导航**：`词典` → `词典质检`

对词典全量词条执行 **10 维自动化检查规则**（基于动态规划最大声母音节切分器与音系规则）：

| 规则 | 严重度 | 说明 |
|------|--------|------|
| 缺少词性 | 🔴 错误 | 义项未设置词性 |
| 拼写无法解析 | 🟡 警告 | 拼写含不在罗马音映射表中的字符 |
| IPA 为空 | 🟡 警告 | 词条没有 IPA 音标 |
| 词形不符合模式 | 🟡 警告 | 词形不满足词性的正则模式 |
| 缺少必填字段 | 🔴 错误 | 缺少词性要求的必填字段 |
| 重复词形 | 🟡 警告 | 词典中存在重复的罗马音拼写 |
| 音节结构违规 | 🟡 警告 | IPA 无法按当前音位配列音节模板合法切分 |
| 命中黑名单 | 🔴 错误 | 词形或音素序列命中音位配列禁用正则 |
| 元音和谐冲突 | 🟡 警告 | 同一词内混用了互斥和谐组的元音 |
| 同音碰撞 / 复合词读音过期 | 🟡 警告 | 不同词条产生完全相同的音位 IPA，或复合词成分读音变更后尚未重算 |

- 每条规则可独立启用/禁用
- 单条问题可标记为「例外」
- 点击词条名称可跳转到词典编辑器

## 统计报告

**导航**：`词典` → `统计`

自动计算并可视化语言的统计数据：

- **词条总数** — 醒目的大号数字
- **词性分布** — 水平条形图，按词性分组
- **音素频率** — 柱状图，展示出现频率最高的 30 个 IPA 音素
- **字符频率** — 柱状图，展示出现频率最高的 30 个罗马音字符
- **二元组合 (Bigram)** — 热力图标签，展示最常见的 40 个双音素组合
- **音节结构分布** — 柱状图，按音节数分布
- **正字法速查表** — 完整的罗马音 → IPA 映射列表

:::tip
统计能帮你发现语言的"偏科"——比如音素太集中、某些词性词汇过少等。
:::
