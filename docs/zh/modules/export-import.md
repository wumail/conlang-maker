# 导出与导入

一键生成出版级参考语法书、多格式词表、拼写检查词典、AI 语言简报与完整工作区备份包。桌面端所有文件导出均走系统原生保存面板，稳定可靠。

**导航**：点击顶部导航栏 `导出 / 导入`

## 导出预设与格式一览

| 格式 | 内容 | 适用场景 |
|------|------|----------|
| **参考语法书（HTML / Typst `.typ`）** | 封面、音系与正字法、内置自造字字体（`@font-face` 内联）、屈折范式与变位类、语法手册章节、**双向词典（造语→释义 & 释义→造语，精确到义项级语料例句引用）**、全量莱比锡标注语料选集 | 在浏览器中离线阅读、打印 PDF，或使用 Typst 编译学术排版级参考书 |
| **PDF** | 完整语言参考文档 | 快速导出可打印的便携参考手册 |
| **Excel (`.xlsx`)** | 多 Sheet 工作簿 | 用表格软件统计分析（音素表、罗马音映射、完整词典） |
| **Hunspell (`.dic` + `.aff`)** | 拼写检查词典对 | 选择 `.dic` 保存路径后，系统在同目录**自动配套生成 `.aff`**（复用统一 6 步形态引擎展开基础词形与屈折形式），可直接导入 LibreOffice 等编辑器 |
| **CSV** | UTF-8 BOM 词典表格 | 轻量备份或与其他词典软件交换数据（完美兼容中文与特殊 IPA 符号） |
| **LLM Prompt (`.md`)** | AI 对话语言简报 | 让大模型快速掌握你的音系、正字法、语法与核心词表（支持复制或保存 `.md`） |
| **工作区整包备份（Workspace Bundle）** | 包含整棵语系树 `.conlang`、全部分支语言数据与自定义 `.ttf`/`.otf` 字体资产 | 跨设备迁移、里程碑完整归档或团队共享整个语系项目 |

## 参考语法书生成器

点击 **「参考语法书」** 卡片打开定制弹窗：

- 可自由勾选要收录的模块章节（音系、书写系统、形态与语法手册、双向词典、语料选集）
- **HTML 模式**：自动将语言生效的 `.ttf`/`.otf` 自造字字体以 Base64 `@font-face` 内嵌进单文件 HTML，发给任何没有安装字体的读者都能原样渲染本族文字
- **Typst 模式**：输出结构清晰的 `.typ` 源码，方便进一步微调版式并编译高精印刷 PDF

## 导入与恢复

- **CSV 批量导入**：自动识别 PolyGlot / Vulgarlang / 通用 CSV 列结构，经过统一批量差异预览（显示新增/冲突范围，支持 `⌘Z` 撤销）后原子导入词典
- **工作区整包恢复**：导入备份包前自动创建项目级安全快照，在单个项目事务内完成原子替换，随时可通过快照管理器无损回滚
