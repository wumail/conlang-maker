# 语法

7 个核心工作区（类型学、句法配置、词性管理、屈折系统、形态音位、派生规则、参考手册），管理语法规则从类型学设定到精确形态推导的完整生命周期。

**导航**：点击顶部导航栏 `语法`

## 类型学与变位类

设置语言的整体形态类型学画像与词类分流机制：

- **形态类型**：孤立语（Isolating）/ 黏着语（Agglutinative，支持槽位链排序）/ 融合语（Fusional，支持多维融合词缀与变位类）/ 多式综合语（Polysynthetic）
- **形态句法对齐**：主宾格（`nom_acc`）/ 作通格（`erg_abs`），与翻译沙盒的小句角色自动联动
- **变位类 / 变格类（Conjugation Classes）**：为同一词性（如动词、名词）定义多个变位类（如第一变位法、第二变位法），并指定词干特征匹配条件或词条显式绑定；规则选择严格遵守变位类归属，调整无关变位类规则的排列顺序不会串扰当前词条结果

## 句法配置

设置语言的基本句法参数：

- **基本语序**：SVO（如英语、中文）、SOV（如日语、韩语）、VSO（如阿拉伯语）、VOS、OVS、OSV
- **修饰语位置**：中心词前（如英语 *big house*）/ 中心词后（如法语 *maison grande*）
- **介词类型**：前置词（*in* the house）/ 后置词（the house *in*）

## 词性管理

自定义词性来定义语言的词类体系：

- 名称、缩写（用于莱比锡 Gloss 标注）
- 词形模式（正则表达式）
- 是否要求释义 / 发音

默认提供 8 种基本词性：名词、动词、形容词、副词、代词、介词、连词、感叹词。

## 屈折系统

### 屈折维度

自定义屈折维度及其值，并可标记某维度对特定词性是否为**必选特征（Obligatory）**：

| 维度 | 示例值 |
|------|--------|
| 数 (Number) | 单数 SG / 复数 PL |
| 格 (Case) | 主格 NOM / 宾格 ACC / 属格 GEN / 与格 DAT |
| 时态 (Tense) | 过去 PST / 现在 PRS / 将来 FUT |
| 人称 (Person) | 第一人称 1 / 第二人称 2 / 第三人称 3 |

每个维度关联到特定词性（例如「格」仅适用于名词和代词）。当一次变形请求缺少必选特征（例如动词指定了过去时却未指定人称或数）时，系统会给出明确的缺失特征提示。

### 屈折规则与统一决策管线

支持 6 种形态操作类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| 前缀 (Prefix) | 词前添加 | `un- + happy` |
| 后缀 (Suffix) | 词后添加 | `cat + -s` |
| 中缀 (Infix) | 词中插入 | 在第 N 个音素后插入 |
| 环缀 (Circumfix) | 头尾同时加 | `ge- ... -t` |
| 重叠 (Reduplication) | 全词/部分重叠 | 完全重叠或首 N 音素 |
| 元音变换 (Ablaut) | 词干元音交替 | `sing → sang` |

**条件逻辑**：每条规则支持 IF/ELSE 分支，根据词尾/词首音素类型或正则匹配选择不同异形态词缀。

**统一 6 步规则决策与推导管线**（范式表、翻译沙盒、语料自动标注、Hunspell 拼写检查导出共用同一套引擎）：

1. **词条不规则覆盖（Irregular Overrides）**：按特征组合精确度（特异性最高者优先）匹配异干互补或不规则词形
2. **所属变位类匹配**：过滤出属于该词条指定变位类（或通用类）的候选规则
3. **适用条件与优先级**：按音系条件、槽位顺序或融合特征覆盖度与显式优先级选定规则，若多条规则同时等权冲突则显式告警
4. **词干与词缀拼接**：注入语素边界标记 `+`（如 `ev+lar`）
5. **形态音位规则（Morphophonology）**：跨 `+` 边界执行同化、脱落、增音或元音和谐，并清除内部 `+`
6. **表层发音生成**：将最终拼写送入正字法与音位变体管线生成 `/…/` 与 `[…]` IPA

### 不规则覆盖（Irregular Overrides）

在屈折系统中可为高频词（如系动词「是」、代词或异干互补词条）直接指定特定维度组合下的表层词形。当同一词条配置了多条覆盖（例如通用过去时覆盖 vs. 第一人称单数过去时覆盖）时，引擎自动选用匹配维度更多、更具体的覆盖项。

### 屈折矩阵与推导步骤追踪

- **屈折矩阵（范式表）**：以网格一览词条或词性在各维度组合下的完整范式，快速发现漏配格位或冲突规则。
- **逐步推导追踪（`InflectionTracePanel`）**：输入测试词并选择词性与特征组合，即可展开查看从词干、命中规则/变位类、语素拼接（含 `+` 边界）、形态音位改写到最终 IPA 的每一步中间结果与缺失必选特征诊断。

### SCA 联动开关与父语言词缀同步

- 每条屈折规则可独立开启 `SCA` 开关，允许历时音变批量改写词缀。
- 子语言还支持**语法词缀拉取同步**（`gram_pull_sync`）：将父语言的屈折/派生词缀与不规则形式套用子语言音变规则演化，并自动检测音变导致的**同形并合（Syncretism）**碰撞。

## 形态音位（Morphophonology）

专门处理词干与词缀拼接处（语素边界 `+`）的音系交替规则：

- **执行时机**：在词缀拼接之后、最终输出之前按优先级升序依次执行；若未定义规则，词缀直接原样拼接。
- **单行规则 DSL 与表单双视图**：支持 `n -> m / _ + p`（鼻音部位同化）、元音和谐、双元音缩合或边界辅音脱落等写法；语境支持 `V`（元音宏）、`C`（辅音宏）、`#`（词边界）与 `+`（语素边界）。
- **底部实时试算栏**：直接输入带 `+` 的拼接串（如 `ev+lar`），即时预览 `ev+lar → evler` 的形态音位变换结果。

## 派生规则

定义词性转换与构词规则，从现有词汇批量生成派生词：

- **词性转换**：源词性 → 目标词性（如 动词 → 名词：施事后缀 `-er`）
- **复用完整形态与形态音位管线**：6 种形态操作及跨 `+` 边界形态音位规则同样生效
- **语义说明与构词溯源**：批量预览并勾选导入词典后，自动写入结构化派生词源与构词成分链接，便于在词族图谱与词源链中双向追溯
- **SCA 联动开关**：每条派生规则可独立设置是否参与历时音变改写
