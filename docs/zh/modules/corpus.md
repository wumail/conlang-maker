# 语料库

以侧边栏 + 标注工作台的分栏布局管理造语文本、莱比锡行间标注（Leipzig Glossing）、人工审校锁定与语料音变演化。

**导航**：点击顶部导航栏 `语料库`

## 文本管理与记忆切换

- 创建 / 编辑 / 删除语料文本，支持标题、描述、标签与本族文字预览
- 保存造语原文与全文自由翻译，并按行维护行级自由译文（Line Translation）
- **跨语言视图记忆**：在多门语言间来回切换编辑时，应用会自动记住每门语言上次打开的语料条目

## 行间标注与词元确认状态（Provenance）

每个分词词元（Token）都具备完整的莱比锡多层标注与审校来源状态：

- **标注字段**：表层词形（Surface form）、语素切分（Morpheme break）、语法标签（Gloss labels）、绑定词条与具体义项（`entry_id` + `sense_id`）、IPA 音标
- **三态来源标记与锁定保护**：
  - **自动（`auto`）**：由自动标注引擎生成的候选分析
  - **已改（`edited`）**：用户手动修改过切分、标签或绑定词条，默认受保护不被覆盖
  - **已确认锁定（`verified`）**：人工终审锁定的分析，批量重算时跳过保护

## 非破坏性自动标注（三种范围模式）

自动标注结合**词典精确匹配**与**形态规则逆向解析**（支持多前缀+词干+多后缀、中缀、环缀、重叠、元音交替及形态音位逆推），并提供三种显式执行范围，**100% 保留已有的逐行自由译文**：

1. **只补空缺（`fill_empty`，默认推荐）**：仅分析尚未标注的空白词元，完全不触碰任何已有标注与人工修订。
2. **重算自动结果（`recompute_auto`）**：当你更新了词典或屈折规则后，重新分析所有状态为 `auto` 的词元，同时严格跳过 `edited` 与 `verified` 的人工成果。
3. **重新分析选中行（`reanalyze_selected`）**：仅针对当前勾选行重新分析；若范围内包含 `edited` / `verified` 的人工词元，系统会先弹出**前后差异预览（Batch Diff Preview）**，逐项确认后才可替换并支持一键 `⌘Z` 整体撤销。

### 候选复核与数字键 `1..9` 速选

- 低置信度或同形多义词（如同一词形对应多个词条或不同变位）会进入**待复核建议面板**。
- 点开词元编辑弹窗时，可直接按键盘数字键 **`1`～`9`** 一键选用对应的候选分析，大幅提速长篇语料校对。

### 行级筛选栏

语料工具栏支持按状态快速过滤标注行（如「只看含未识别词元的行」「只看待复核行」「只看未锁定行」），聚焦尚未完成的句子。

## 语料内就地造词与补绑（QuickLex 抽屉）

写长篇语料遇到生词时，无需离开语料库切换到词典页：

- 在未识别词元上点击**「就地造词 / 绑定已有词条」**打开右侧 `QuickLex` 抽屉
- **新建词条**：直接填写词形、词性、释义、概念绑定并保存入库，同时自动回填当前语料词元的绑定、标签与 IPA
- **绑定已有词条**：搜索词典现有词条或特定义项完成关联
- **单步复合撤销**：就地造词并回填语料被打包为单步复合操作，按一次 `⌘Z` / `Ctrl+Z` 即可同时撤回新建词条与语料标注改动

## 语料例句反向索引（Concordance）

在词典编辑器或通过 MCP `corpus_concordance` 查询任意词条时，系统会自动反向扫描全部语料，汇总该词条（含精确词条/义项绑定、语素词干匹配与已知屈折变体，且自动排除已绑定给其他同形异义词的词元）的真实语境例句，点击即可跳回对应语料行。

## 语料 SCA 差异预览与应用

点击 **「预览并应用 SCA 到语料」**，可在批量差异预览弹窗中逐条勾选原文与词元表层的音变改写，确认后原子写回并按安全范围刷新自动标注。
