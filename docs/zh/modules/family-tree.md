# 语系树

管理语言的谱系关系，从一个原始语言派生出子语言树。

**导航**：点击左侧 `语系树`

当你的原始语言足够成熟后，可以创建它的子语言，模拟真实世界中的语言分化。

## 拓扑可视化

树形结构展示所有语言，高亮当前活动语言，点击节点可切换到该语言。

## 派生语言

从父语言创建子语言，复制父语言的音系、语法、词典与语料数据，作为独立分支进行修改。

- 子语言会继承词条 `entry_id`，用于稳定的父子词对齐与后续同步
- 子语言的 SCA 规则文件初始化为空，建议按分支历史单独配置
- 派生完成后会自动切换到新创建的子语言

### 操作步骤

1. 在语系树中选择父语言
2. 点击 **「派生」** 按钮
3. 输入子语言名称
4. 系统会完整复制父语言的所有数据

## 拉取同步

拉取同步会比较父语言与子语言中的继承词条，生成「新增」与「更新」候选：

- **新增**：父语言有、子语言还没有的继承词
- **更新**：父或子发生变化且可安全合并的继承词
- **冲突**：父与子都变更时保留子语言版本，不自动覆盖

点击 **拉取并应用音变** 时，候选词会经过当前子语言 SCA 规则处理，并写入词源链（`parent_entry_id` + `applied_sound_changes`）。

:::tip
释义（gloss/definitions/examples）差异不触发拉取同步。释义属于子语言可独立演化内容，不会因为父语言释义变化而被覆盖。
:::

### 旧数据迁移

若历史项目缺少 `parent_entry_id` / `source_language_id` 等继承字段，可在拉取同步面板使用：

- **预览迁移（dry-run）**：仅扫描并显示预计修复量，不写入文件
- **迁移旧词条**：执行实际修复并写回文件

:::tip
如果后续给父语言添加了新词，在子语言中打开语系树，点击 **「拉取」** 即可自动同步。
:::

## 借词与跨项目借入

支持从本语系任意语言或**其他已注册语系项目**借入词汇：

1. 点击 **「借词」** 打开借词面板
2. 按 **「项目 → 语言 → 词条 → 义项」** 选择供语来源（跨项目选择时完整展示外部项目的全部语言）
3. 选择目标词条后导入，系统自动写入稳定引用并保存 **借入来源快照**（保留借入当时的词形、释义、供语名与语系名，即使供语日后改写或删除也不丢失依据）

## 历时语法词缀同步

除词典拉取同步外，子语言还支持从父语言拉取同步屈折与派生词缀：

- 将父语言词缀通过当前子语言的 SCA 音变规则推演生成预览清单
- 自动检测音变后是否导致不同语法格/时态发生 **同音中和（Homophone Neutralization）** 并给出预警，确认后再写回语法配置

## 全语系同源词矩阵

点击语系页头部的 **「同源词矩阵」** 按钮，即可在弹窗中横向对照整棵语系的核心概念演化：

- **概念中心视图**：基于 158 项核心概念与项目自定义概念，按语言列展示同源组（同色标识源自同一祖语词条）、借词与独立创新词。
- **专项筛选与固定双行栏**：支持按语义域、「只看已有词形」、借词替代、词形变化、多候选（`+1`）与断链快速过滤。
- **候选抽屉与空缺管理**：点击任意单元格可查看全部候选义项、手动置顶主词、直接原地造词或绑定已有义项，也可将空白格标记为待定（`TBD`）、迂回表达（`Periphrastic`）或确认无独立词（`Confirmed Absent`）。

## 多语言工作区与视图记忆

- **顶部紧凑语言切换器**：点击左上角当前语言名称即可直接展开语系下拉列表快速切换；应用会自动记住每门语言上次正在查看的词条与语料文本，切回时无缝恢复上下文
- **语言回收站**：删除叶节点语言会安全移入项目 `.conlang-maker/trash/` 回收站，随时可无损恢复
