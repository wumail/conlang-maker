# 书写系统

管理语言的本族文字字体（OpenType `.ttf` / `.otf`）、字符参考标注与字形排版质量检查。

**导航**：点击顶部导航栏 `书写`

## 字体导入与语系继承

Conlang Maker 采用真实的字体驱动渲染架构，词典、屈折范式表、翻译沙盒、语料库与出版级参考语法书共用同一套本族文字排版管线：

- **自有字体（`own`）**：为当前语言导入 `.ttf` 或 `.otf` 字体（上限 20 MB，自动校验 OpenType 魔数与 `cmap` 表）。
- **祖先继承（`inherited`）**：若当前子语言尚未导入专属字体，系统自动沿 `parent_id` 向上回退继承最近的祖先语言字体；点击「清除自有字体」即可恢复继承。
- **OpenType 样式集（`ss01` 等）**：当字体编译了可选样式特性（如印刷体/手写体切换 `ss01`）时，界面自动展示开关并持久化到 `font_features`。
- **音素级字体输入（`font_input`）**：支持将音素序列精确映射为字体输入串（区分双元音与跨音节相邻元音、保留 `/k h/` 与二合字母边界），并可对继承词启用 `use_parent_phonemes` 保留历史正字法。

## 字形网格与基准线标尺

导入或继承字体后，书写页展示完整的已编码字符网格：

- **度量标尺叠加层**：支持一键开启基线（Baseline）、大写高度（Cap Height）、x 高度（x-Height）、上伸部（Ascender）与下伸部（Descender）参考线，直观检查字形高低是否对齐。
- **放大预览检视器**：点击任意字形单元格，可查看大尺寸轮廓、Unicode 码位、前进宽度（Advance Width）与左右轴承距（LSB / RSB）。

## 字符参考标注

你可以为字体中的码位维护结构化参考标注：

- **标注字段**：显示名称（Label）、字符类别（辅音字、元音字、附标、标点、数字等）与对应音素。
- **父语同步**：子语言默认继承父语言的字形参考标注；编辑某条继承标注会自动转为本地覆盖，也可一键从父语言同步新增标注。

## 异常字形几何诊断

内置基于 HarfBuzz 的排版与度量审计面板，自动扫描整套字体并定位常见造字工程问题：

- 宽度异常（过窄、过宽或零宽非组合符）
- 越界上下伸（超出 `ascender` / `descender` 安全区导致行距裁切）
- 空白轮廓或 `.notdef` 缺失字形
- 多字符连字（`liga` / `calt` / `ccmp`）未生效或残留拉丁占位字形（配合 MCP `font_audit_coverage` / `font_audit_geometry` 可对整棵语系树批量审计）
