# 翻译沙盒

交互式造句、形态变形与句法重排试验台，用来快速验证你的词典、形态规则、语序与本族文字排版是否协同工作。

**导航**：点击顶部导航栏 `沙盒`

## 核心工作原理：概念/释义查词 → 形态屈折 → 句法重排

翻译沙盒接收的是**源语言概念或释义词（Gloss）**（例如英文 `dog` 或中文 `狗`，对应词典义项中的 `gloss` 或绑定概念），而不是直接输入未知的外部自然语言句子做字母转写：

1. **词典查词**：按输入的释义词（如 `dog`）在当前语言词典中匹配词条；若词典中尚未收录对应释义词，沙盒会以 `?dog?` 高亮提示缺词（引导你先补充词条或改用已收录的释义词）。
2. **统一形态推导**：复用语法模块完整的 6 步形态引擎（不规则覆盖 → 变位类 → 屈折规则 → `+` 形态音位交替 → IPA 生成）。
3. **四行对照输出**：同时渲染**本族文字（`.conlang-script`）**、**造语表层词形**、**莱比锡语素标签（Gloss）**与 **IPA 音标**，并附带逐步推导说明与缺失格标记告警。

## 1. 标签屈折卡片（Gloss-Tag 模式）

直接输入 `释义词-TAG1-TAG2` 格式的序列（例如 `star-PL shine-PST` 或 `星-PL 闪耀-PST`）：

- 自动从当前语言词典检索 `star`、`shine` 对应的词根与所属变位类
- 按标签（`PL`、`PST` 等）套用屈折与形态音位规则
- 点击任意输出词元可展开查看该词的形态推导步骤

## 2. 递归小句构建器（Clause Builder）

结构化组装完整句子并验证句法配置与格对齐体系：

- **论元与修饰结构**：填写主语（S/A）、动词谓语（V）、宾语（O/P），支持添加修饰语（形容词/限定词）、介词短语（PP）以及**嵌套子句 / 从句（Recursive Subclauses）**
- **形态句法对齐联动**：
  - **主宾格（`nom_acc`）**：及物与不及物主语统一标记主格（NOM），及物宾语标记宾格（ACC）
  - **作通格（`erg_abs`）**：及物施事（A）自动推断作格（ERG），不及物主语（S）与及物受事（P）自动推断通格（ABS）；若语法中尚未配置对应格维度值，沙盒会给出黄色提示而不会静默吞掉参数
- **自动语序重排与短语树预览**：按语法中的基本语序（SVO / SOV / VSO 等）、修饰语前后位置与前/后置词设置自动排列线性词序，并在右下角同步展示结构化**短语树（Phrase Tree）**与句法推导步骤

## 3. 单点词形试算

如果只想单独验证某一个词条在特定维度组合下的变形过程，也可配合 `语法 -> 屈折测试` 或全局命令面板（`⌘K` / `Ctrl+K` 输入 `=`）即时试算。
