# 从零构建人工语言

> 本指南以一个完整的创作流程为线索，手把手引导你从零开始构建一门功能完整的人工语言与语系。

:::tip
创造语言是一个迭代过程。你不需要严格按本手册的顺序操作——随时可以在各模块间跳转。新建项目后，应用也会提供**三路径新手引导弹窗**（从预设快速起步 / 从概念词表造词 / 空白自由搭建），帮你一键进入状态。
:::

## 开始之前

### 启动应用与工作区

Conlang Maker 是本地优先的桌面应用，双击打开即可。首次启动时创建一个语系项目，应用会自动生成初始祖语（**Proto Language**），后续所有分支方言与子语言都可从此派生演进。

### 界面与全局快捷键概览

- **顶部左上语言切换器**：点击当前语言名称即可展开语系分支列表，在不同语言间切换时会自动记住你在词典和语料库的浏览位置
- **顶部主导航栏**：`音系` · `书写` · `词典` · `造词器` · `语法` · `语料库` · `沙盒` · `语系` · `音变` · `导出 / 导入`
- **全局命令面板（`⌘K` / `Ctrl+K`）**：
  - 直接输入关键词：跨模块搜索词条、语法与页面并一键跳转
  - 输入 `>` 前缀：执行快捷动作（切换语言、打开同源词矩阵、运行质检等）
  - 输入 `=` 前缀：就地试算罗马音转 IPA、音变规则或形态屈折结果
- **全局撤销 / 重做（`⌘Z` / `⇧⌘Z`）**：无论是编辑单个字段还是执行批量音变、父词同步、语料就地造词，均可安全撤销
- **右上角 ⚡ 快速录入与保存状态胶囊**：随时连按回车极速录词，保存状态实时可见

## 第一步：搭建语音系统

**导航**：`音系` → `音素表`

决定你的语言使用哪些元音与辅音：

1. **使用预设（推荐新手）**：点击 **「预设」** 浏览 12 种语言风格（夏威夷语风、精灵语风、斯拉夫语风、阿拉伯语风等），一键加载
2. **手动点选**：在 IPA 辅音表与元音梯形图中点击音素（高亮 = 已选），点击音素可试听标准发音

## 第二步：设计正字法与音位变体

**导航**：`音系` → `罗马音` / `音位配列` / `音位变体`

1. 在 **罗马音** 中添加拼写映射（如 `sh → ʃ`），右侧**正字法健康诊断**会自动检查冲突规则、遮蔽规则与被改写却不可达的音素
2. 在 **音位配列** 中设置音素类宏（`C`、`V`）、音节模板（如 `(C)V(C)`）、黑名单与元音和谐
3. 可选在 **音位变体** 中配置语境变音规则，同时产出音位 `/…/` 与表层 `[…]` IPA

## 第三步（可选）：接入本族文字字体

**导航**：`书写`

如果你为语言制作了 `.ttf` 或 `.otf` 自造字字体：

1. 导入字体文件（子语言可自动继承祖语字体）
2. 在字符网格中建立字形参考标注，使用 HarfBuzz 实时排版预览与字形几何审计检查连字（`GSUB`）和度量对齐
3. 导入后，词典、语料库、沙盒与导出的参考语法书都会同步渲染本族文字

## 第四步：生成与打磨词典

**导航**：`造词器` → `词典`

1. 在 **造词器** 中按音节模板批量生成候选词，可一键对齐 **Swadesh 100 / Leipzig-Jakarta** 核心概念词表后导入词典
2. 在 **词典** 中精细编辑词条，或点击标题右侧的 **表格视图** 按钮打开弹窗连续批量录入、粘贴 TSV 并按义项绑定标准概念（`concept_id`）
3. 为派生词与复合词添加**构词成分**，在词源面板点击查看**交互式词源追溯链**与词族图谱
4. 运行 **词典质检**（11 项检查）保持词库严密一致

## 第五步：建立语法与形态音位

**导航**：`语法`

1. **类型学与句法**：选择孤立/黏着/融合类型、主宾格（`nom_acc`）或作通格（`erg_abs`）对齐，以及基本语序（SVO / SOV / VSO 等）與变位类
2. **屈折系统**：定义维度（数、格、时态、人称及必选标记）、6 类屈折规则与高频词**不规则覆盖**
3. **形态音位**：在词素边界 `+` 上定义同化、脱落或元音和谐规则（如 `ev+lar → evler`），并在底部试算栏即时验证
4. **屈折矩阵与推导追踪**：检查完整范式网格与 6 步推导明细

## 第六步：在翻译沙盒与语料库中实战检验

**导航**：`沙盒` / `语料库`

1. **翻译沙盒**：用 `gloss-TAG` 模式或**递归小句构建器**（支持修饰语、介词短语与嵌套从句）检验语序重排、格标记推断与本族文字渲染
2. **语料库**：撰写长篇文本与自由译文，使用**非破坏性自动标注**（默认「只补空缺」，保护已改/已锁定词元与行译文），数字键 `1..9` 速选候选，遇到生词直接打开 `QuickLex` 抽屉就地造词并关联

## 第七步：演化整棵语系与同源词矩阵

**导航**：`语系` / `音变`

1. 在 **语系** 页从父语言派生子语言
2. 在 **音变** 页用单行 DSL 编写历时音变规则，通过虚拟化批量差异预览应用到词典与语法词缀
3. 支持跨语言/跨项目**借词**（保存供词历史快照）与父语言**拉取同步**
4. 在语系页点击 **「同源词矩阵」** 打开全语系概念对照弹窗，一目了然审视同源继承组、借词替代与独立构词创新

## 第八步：出版导出与 AI 协作

**导航**：`导出 / 导入` / `MCP 设置`

- 导出内嵌字体的单文件 **HTML / Typst 参考语法书**、**Excel**、自动配对 `.aff` 的 **Hunspell `.dic` 拼写词典**、**LLM Prompt** 或 **工作区整包备份**
- 开启内置 **MCP 服务**（84 个语义工具），让 Claude Code、Cursor 等 AI 助手在乐观锁与事务快照保护下协助审校词典、推演音变与填充语系
