# Corpus

Manage conlang texts, Leipzig-standard interlinear glossing, human-verified annotations, and diachronic text evolution in a split sidebar + workbench layout.

**Navigate**: click `Corpus` in the top navigation bar.

## Text Management & View Memory

- Create, edit, and delete corpus texts with title, description, tags, and native-script rendering
- Store full raw text, passage-level free translation, and per-line translations
- **Per-Language View Memory**: Switching between languages automatically remembers which corpus text you last had open in each language

## Interlinear Glossing & Token Provenance

Every token supports full Leipzig multi-tier annotation plus explicit provenance tracking so automated passes never overwrite human work:

- **Tiers**: Surface form, morpheme break, gloss labels, linked lexicon `entry_id` + `sense_id`, and IPA
- **Provenance States**:
  - **`auto`**: Generated by the morphological auto-glosser
  - **`edited`**: Manually edited by you — protected by default during re-runs
  - **`verified` (Locked)**: Explicitly verified and locked against accidental overwrite

## Non-Destructive Auto-Gloss (3 Scope Modes)

The auto-gloss engine combines **exact lexicon lookup** with **reverse morphological parsing** (multi-prefix + stem + multi-suffix, infixes, circumfixes, reduplication, ablaut, and morphophonological alternations) while **100% preserving existing line translations**:

1. **Fill Empty Only (`fill_empty`, default)**: Analyzes only unannotated tokens, leaving all existing annotations untouched.
2. **Recompute Auto Only (`recompute_auto`)**: Refreshes `auto` tokens after lexicon or grammar updates while strictly preserving `edited` and `verified` tokens.
3. **Reanalyze Selected Lines (`reanalyze_selected`)**: Re-runs analysis on selected lines; if any `edited` or `verified` tokens would be replaced, a **Batch Diff Preview** modal shows exact before/after changes first, and the entire pass can be undone in one step with `⌘Z` / `Ctrl+Z`.

### Candidate Review & `1..9` Hotkeys

- Ambiguous homographs or lower-confidence parses queue into the **Pending Suggestions** panel.
- Inside the token editor popover, press number keys **`1`–`9`** to pick candidate parses instantaneously without touching the mouse.

### Line Filter Bar

Filter gloss lines by completion status (unresolved tokens, pending suggestions, or unverified tokens) to focus review on unfinished sentences.

## In-Context Word Coining (`QuickLex` Drawer)

When writing a passage introduces a new word, coin or link it without leaving the Corpus page:

- Click **Coin / Link Word** on any unresolved token to open the `QuickLex` drawer.
- **Create New Entry**: Enter romanization, POS, gloss, and concept ID to add the word to your lexicon and immediately link + gloss the corpus token.
- **Bind Existing Entry**: Search existing lexicon entries and specific senses to link.
- **Single-Step Composite Undo**: Coining a word + linking the corpus token is recorded as a single composite undo action — one `⌘Z` / `Ctrl+Z` cleanly reverts both the lexicon addition and the corpus edit.

## Corpus Concordance

Every linked token and inflected stem feeds the **Corpus Concordance** reverse index (visible on each word's Lexicon detail card and via MCP `corpus_concordance`), with homograph protection and polysemous sense awareness so clicking any attestation jumps straight back to the exact corpus line.

## Apply SCA to Corpus with Diff Preview

Use **Preview & Apply SCA to Corpus** to inspect before/after sound-change diffs across raw lines and token surfaces, deselect unwanted items, and commit atomically.
